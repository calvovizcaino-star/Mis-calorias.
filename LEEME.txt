MIS CALORÍAS — PRIMERA VERSIÓN CON OCR

La pantalla Foto etiqueta incorpora un lector OCR con Tesseract.js.
- Requiere conexión a Internet para descargar la biblioteca y los datos de idioma en esta versión.
- No usa una API de pago ni una clave secreta.
- No es todavía OCR totalmente offline.
- La detección automática de calorías y macros es heurística; revisa siempre los campos.
- El nombre del producto y el peso neto no se extraen de forma fiable y deben comprobarse manualmente.
- La lectura no guarda el alimento por sí sola: copia los datos al formulario Crear alimento y el usuario debe pulsar Guardar alimento.

Sube index.html, sw.js, manifest.json e iconos al repositorio GitHub existente.
